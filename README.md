# ExpenseFlow 💰

A professional and responsive **Personal Expense Tracker** built with HTML, CSS, and JavaScript.

ExpenseFlow helps users record expenses, manage their monthly budget, view transactions, and understand spending patterns through analytics.

## 🚀 Live Demo

[View ExpenseFlow Live](YOUR_GITHUB_PAGES_LINK)

## 📌 Features

- Add and manage expenses
- Add income transactions
- Edit transactions
- Delete transactions
- Search transactions
- Filter by category
- Filter by date
- Sort transactions
- Monthly budget tracking
- Spending progress indicator
- Recent activity
- Spending by category analytics
- Spending trend analytics
- Add Expense modal
- Light/Dark theme
- LocalStorage data persistence
- CSV transaction export
- Responsive design
- Input validation and secure HTML rendering

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- LocalStorage
- Canvas API
- Git
- GitHub
- GitHub Pages
